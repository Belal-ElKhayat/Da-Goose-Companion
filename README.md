## 🚀 Features

### 1. 🤖 AI Screen Peeker
<p align="center">
  <img src="assets/Screen peeker full.png" alt="AI Screen Peeker" width="85%">
</p>

* **Local OCR & Multimodal AI:** Peeks at your active window to judge your coding loops or reading habits[cite: 4].
* **Zero Bloat:** Built purely with Python & PyQt6 vector rendering—no heavy image assets or slow resource hogs[cite: 4].
* **Configurable API:** Easily plug in your own Gemini key via the settings menu[cite: 4].

---

### 2. 🚫 Anti-Doomscroll Guard
<p align="center">
  <img src="assets/ANTI DOOM SCROLL.PNG" alt="Anti-Doomscroll Guard" width="85%">
</p>

* **Brainrot Detection:** Tracks active browser windows to catch you spending hours on short-form feeds.
* **Aggressive Interventions:** Red-eyed judging mode[cite: 5], warning sounds, and speech bubbles ready to scold you back to work.

---

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **GUI Framework:** PyQt6 (Frameless, transparent, taskbar-anchored overlays)
* **AI Integration:** Google Gemini API (Multimodal screen analysis)
* **Window Tracking:** Windows API / active title polling
